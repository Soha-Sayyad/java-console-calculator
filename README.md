# Java Console Calculator

A simple console-based calculator built using Java. It performs basic arithmetic operations based on user input.

## Features

* Addition (`+`)
* Subtraction (`-`)
* Multiplication (`*`)
* Division (`/`)
* Handles division by zero
* Handles invalid operators

## Technologies Used

* Java
* `Scanner` for user input
* `switch` statement for selecting operations

## How to Run

1. Clone the repository or download the project.
2. Compile the Java file:

```bash
javac console_calculator.java
```

3. Run the program:

```bash
java console_calculator
```

## Usage

The program asks the user to enter:

1. First number
2. Second number
3. Operator (`+`, `-`, `*`, `/`)

### Example

```text
Enter 1st number:
10

Enter 2nd number:
5

Enter operator (+,-,*,/):
*

Result=50.0
```

## Error Handling

### Division by Zero

```text
Number cannot be divided by 0.
```

### Invalid Operator

```text
Invalid Operator.
```
